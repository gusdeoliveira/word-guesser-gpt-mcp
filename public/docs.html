Tools & Widgets

Word Guesser is a daily word game for ChatGPT. Players have six attempts to find a five-letter English or Brazilian Portuguese word, with progress kept locally on their device.

MCP tools

open_word_game

Opens or resumes the daily puzzle. It selects English by default and Brazilian Portuguese when ChatGPT supplies Brazil as the user's coarse location, unless the user chooses a language.

language?: auto | en | pt-BR model + app visible read-only

submit_word_guess

Validates a guess from the game widget and returns letter-by-letter feedback. The answer remains hidden until the player wins or uses the sixth accepted attempt.

app only read-only idempotent

Widget resource

ui://word-guesser/game-v1.html

A CSP-friendly React interface containing the game board, keyboard, help dialog, language switch, dark-theme support, and local progress persistence.

text/html;profile=mcp-app no external domains

Data and state

The MCP server is stateless. Puzzle progress is saved in browser storage and mirrored to ChatGPT widget state. See the Privacy Policy for the complete data disclosure.
